# Security Policy

## Reporting a Vulnerability

`gateway` sits directly in the request path between your application and
model providers, so security reports are taken seriously.

**Please do not open a public issue for a security vulnerability.**

Instead, report it privately using GitHub's built-in flow:

1. Go to the affected repository's **Security** tab.
2. Click **"Report a vulnerability"** to open a private security advisory.

If the affected repo doesn't have Security Advisories enabled, use the
[private advisory form on this `.github` repo](https://github.com/kelvran/.github/security/advisories/new)
instead and mention which repo it affects.

## Response Time

We aim to acknowledge new reports within **48 hours** and to provide a
remediation timeline once the issue is confirmed.

## Supported Versions

Only the latest released version of each repo is supported with security
fixes.
